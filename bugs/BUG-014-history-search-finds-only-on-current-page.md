# BUG-014: [API][UI] Поиск по истории находит совпадения только на текущей странице

## Краткое описание

Параметр `q` применяется **после** нарезки страницы, а не по всем операциям с учётом фильтров. Часть совпадений не находится; счётчик "Найдено" вводит в заблуждение.

## Severity / Priority

|              | Оценка | Обоснование                       |
| ------------ | ------ | --------------------------------- |
| **Severity** | Major  | Ломает доверие к поиску и выписке |
| **Priority** | Medium | Ядро раздела "История"            |

## Окружение

- ОС: Windows 10
- Браузер: Chrome

## Предусловия

- Учётка: `ivanov` / `password123`, счёт `acc-1` (после reset около 199 операций)

1. Открыть https://fulcrum81.github.io/alfa-task/
2. В DevTools браузера (F12 → Console) сбросить стенд и войти:

```js
await fetch('https://fulcrum81.github.io/alfa-task/api/__test__/reset', { method: 'POST' });

const login = await fetch('https://fulcrum81.github.io/alfa-task/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ login: 'ivanov', password: 'password123' })
}).then((response) => response.json());

const token = login.data.token;
```

## Шаги воспроизведения

### API

1. Запросить первую страницу истории **с** поиском:

```js
const res = await fetch(
  'https://fulcrum81.github.io/alfa-task/api/transactions?accountId=acc-1&limit=10&q=' +
    encodeURIComponent('Пятёрочка'),
  { headers: { Authorization: `Bearer ${token}` } }
);
const body = await res.json();
console.log('status', res.status);
console.log('total', body.data?.total);
console.log('items.length', body.data?.items?.length);
console.log(
  'counterparties',
  body.data?.items?.map((t) => t.counterparty)
);
```

2. (Контроль) Без `q` посчитать, сколько раз "Пятёрочка" реально есть среди всех 199 операций `acc-1` — после reset это **11**.

Что делает API-шаг: `GET /api/transactions` с `q=Пятёрочка`. По п.17 сервер должен сначала отфильтровать **все** операции по запросу, потом пагинировать и отдать `total` = числу найденных. Сейчас `q` применяется уже к нарезанной странице из 10 записей.

### UI

3. "История" → счёт "Текущий" → поиск "Пятёрочка" → сравнить строку "Найдено: …" с числом строк в таблице.

## Фактический результат

| Где     | Факт                                                                                                                                                                                                               |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **API** | **200**; `total: 199` (как без поиска); `items.length: 1` — в выдаче только совпадение с **первой** страницы из 10. Остальные совпадения (всего **11** по счёту) на других страницах **не** попадают в ответ с `q` |
| **UI**  | "Найдено: 199 операций", в таблице 0–1 строка по запросу                                                                                                                                                           |

## Ожидаемый результат

| Где        | Ожидание                                                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **API**    | Поиск по всем операциям с учётом фильтров, **затем** пагинация. Для `q=Пятёрочка` после reset: `total: 11` (число найденных), на первой странице `limit=10` — до 10 из этих 11. |
| **UI**     | "Найдено" = числу найденных (11), таблица показывает страницу результатов поиска                                                                                                |
| Требование | `docs/ASSIGNMENT.md` п.17; `docs/openapi.yaml` → параметр `q`                                                                                                                   |
