# BUG-020: [UI] Одинаковые суммы отображаются в разном формате в истории, на счетах, картах и в алерте

## Краткое описание

Одна и та же денежная величина форматируется по-разному: история, карточки счетов, итог, карты, алерт перевода — разные правила (пробелы, запятая/точка, число знаков).

## Severity / Priority

| | Оценка | Обоснование |
|---|---|---|
| **Severity** | Minor | UX-консистентность |
| **Priority** | Low | Ниже багов про деньги и доступ |

## Окружение

- ОС: Windows 10
- Браузер: Chrome

## Предусловия

- Учётка: `ivanov` / `password123`

1. Открыть https://fulcrum81.github.io/alfa-task/
2. В DevTools браузера (F12 → Console) сбросить стенд:

```js
await fetch('https://fulcrum81.github.io/alfa-task/api/__test__/reset', { method: 'POST' });
```

3. Войти в UI: `ivanov` / `password123`.

## Шаги воспроизведения

1. Зафиксировать формат сумм на дашборде (карточки счетов и "Всего на счетах").
2. Открыть "История операций" — сравнить тот же порядок величин.
3. Сделать небольшой перевод — смотреть алерт/подтверждение (сумма, комиссия).
4. Открыть "Карты" — дневной лимит.

## Фактический результат

| Место | Пример |
|---|---|
| История | `32,90 Br` |
| Дашборд, счёт | `1284.51 Br` |
| Дашборд, итог | `6684.51 Br` / `1082.1 Br` |
| Карты | `1 500 Br` |
| Алерт перевода | `комиссия: 2 Br` |

Отдельно: BUG-019 (`1082.1` вместо двух знаков на итоге), BUG-023 (float-хвост на итоге).

## Ожидаемый результат

- Единый формат суммы (и даты) во всех разделах
- Требование: `docs/ASSIGNMENT.md` п.20
