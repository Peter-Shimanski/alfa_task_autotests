# BUG-019: [UI] Итог "Всего на счетах" содержит один знак после запятой вместо двух знаков после запятой

## Краткое описание

По п.21 итог должен отображаться **с копейками** — всегда два знака после разделителя (например `1082.10` / `1 082,10`). У `petrova` на дашборде видно `**1082.1`**: хвост из одного знака, как сырое JS-число, без обязательных копеек.

## Severity / Priority

|              | Оценка | Обоснование                             |
| ------------ | ------ | --------------------------------------- |
| **Severity** | Minor  | Ошибка отображения, проводки не ломает  |
| **Priority** | Low    | П.21 ТЗ; ниже финансовых/security багов |

## Окружение

- ОС: Windows 10
- Браузер: Chrome

## Предусловия

- Учётка: `petrova` / `qwerty123`

1. Открыть https://fulcrum81.github.io/alfa-task/
2. В DevTools браузера (F12 → Console) сбросить стенд:

```js
await fetch('https://fulcrum81.github.io/alfa-task/api/__test__/reset', { method: 'POST' });
```

## Шаги воспроизведения

1. В UI войти как **petrova** → "Счета" / дашборд → посмотреть блок "Всего на счетах".

## Фактический результат

| Что смотреть | Факт                                                          |
| ------------ | ------------------------------------------------------------- |
| Дашборд      | `**1082.1 Br**` — нет двух знаков / единого денежного формата |
| API          | Балансы в state могут быть корректны; баг в **отображении**   |

## Ожидаемый результат

- Итог с копейками (например `1 082,10 Br`)
- Требование: `docs/ASSIGNMENT.md` п.21 (связано с п.20)

См. также: [BUG-023](./BUG-023-dashboard-total-shows-float-tail.md) — float-хвост на том же блоке.
