## Что ок

- Списки `/api/accounts` и `/api/cards` только свои — **п.9** (только списки; точечный доступ к чужому — баги)
- Комиссия **0** между своими — **п.5** (половина пункта; 1,5% / округление до копеек — BUG-008)
- В подтверждении перевода комиссия показывается — **п.7** (факт показа; формат суммы — BUG-020)
- Дневной лимит по локальным суткам, превышение отклоняется — **п.6**
- При нехватке средств баланс не меняется — **п.3** (бизнес-отказ; HTTP 200 — BUG-013, UI до submit — BUG-018)
- Пагинация истории на **API** без дыр/`hasMore` — **п.16** (слой API; UI последней страницы — BUG-021)
- Даты в истории в едином формате — **п.20** (даты; суммы — BUG-020)
- Reset `POST /api/__test__/reset` возвращает seed
- Базовая мобильная вёрстка: узкий viewport читаем, экраны/навигация не разъезжаются (в ТЗ отдельного пункта нет)
