# BUG-023: [UI] Итог "Всего на счетах" с float-хвостом после мелкого перевода

## Краткое описание

После внутреннего перевода на `0.15` итог на дашборде у `ivanov` может показаться с артефактом плавающей точки, например `6684.509999999999`, вместо двух знаков копеек.

## Severity / Priority

| | Оценка | Обоснование |
|---|---|---|
| **Severity** | Minor | Ошибка отображения, проводки не ломает |
| **Priority** | Low | П.21 ТЗ («без артефактов вычислений») |

## Окружение

- ОС: Windows 10
- Браузер: Chrome

## Предусловия

- Учётка: `ivanov` / `password123`

1. Открыть https://fulcrum81.github.io/alfa-task/
2. В DevTools браузера (F12 → Console) сбросить стенд:

```js
await fetch('https://fulcrum81.github.io/alfa-task/api/__test__/reset', { method: 'POST' });
```

## Шаги воспроизведения

1. В UI войти как **ivanov**.
2. "Перевод" → "Между своими счетами" → сумма `0.15` → отправить.
3. Открыть "Счета" / дашборд → посмотреть блок "Всего на счетах".

## Фактический результат

| Что смотреть | Факт |
|---|---|
| Дашборд | Возможен длинный float-хвост (**`6684.509999999999`**) |
| API | Балансы в state могут быть корректны; баг в **отображении** |

## Ожидаемый результат

- Итог без артефактов float, с двумя знаками после разделителя (например `6 684,51 Br`)
- Требование: `docs/ASSIGNMENT.md` п.21 (связано с п.20)

См. также: [BUG-019](./BUG-019-dashboard-total-missing-cents.md) — у `petrova` на том же блоке один знак (`1082.1`) вместо двух.
