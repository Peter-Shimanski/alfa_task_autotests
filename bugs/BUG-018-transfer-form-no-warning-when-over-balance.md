# BUG-018: [UI] Возможно отправить сумму больше остатка — форма не предупреждает до submit

## Краткое описание

Если сумма больше "Доступно на счёте", форма всё равно даёт нажать "Перевести". Ошибка появляется только после ответа сервера, не до отправки.

## Severity / Priority

| | Оценка | Обоснование |
|---|---|---|
| **Severity** | Minor | В основном UX; серверная проверка есть отдельно |
| **Priority** | Medium | Прямо требует п.22; частый сценарий |

## Окружение

- ОС: Windows 10
- Браузер: Chrome

## Предусловия

- Учётка: `ivanov` / `password123`

1. Открыть https://fulcrum81.github.io/alfa-task/
2. В DevTools браузера (F12 → Console) сбросить стенд:

```js
await fetch('https://fulcrum81.github.io/alfa-task/api/__test__/reset', { method: 'POST' });
```

3. Войти через UI: логин `ivanov`, пароль `password123`.

## Шаги воспроизведения

1. Открыть раздел "Перевод".
2. Выбрать internal-перевод между своими счетами (по умолчанию).
3. В поле суммы ввести значение больше "Доступно на счёте", например `99999`.
4. **Не** нажимая "Перевести", проверить: есть ли на форме предупреждение / блокировка кнопки.
5. (Опционально) Нажать "Перевести" — отказ приходит только от API (см. BUG-013).

## Фактический результат

| Где | Факт |
|---|---|
| UI до submit | Предупреждения **нет**; кнопка "Перевести" **доступна** |
| UI после submit | Ошибка (если есть) — уже после ответа `./api/transfers` |
| API | Запрос уходит; см. BUG-013 про HTTP **200** при отказе |

## Ожидаемый результат

- До submit видно, что сумма недопустима
- Заведомо некорректный запрос не уходит
- Требование: `docs/ASSIGNMENT.md` п.22
